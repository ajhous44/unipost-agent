# unipost-agent

The UniPost skill for AI agents. It teaches any agent that reads Markdown skills (Claude Code, Codex, Cursor, OpenClaw, Hermes, and the rest of the `skills` ecosystem) how to schedule social media posts through UniPost's hosted MCP server: schedule posts that publish on time, or wait for your approval if you've turned that on.

## Install

```bash
npx skills add ajhous44/unipost-agent
```

Then connect your agent to `https://mcp.unipost.ai/mcp`. Per-agent setup pages: https://unipost.ai/agents

## What's inside

- [SKILL.md](SKILL.md): how to connect, the rules (scheduling and optional approval, X credits, media, budgets), every MCP tool with its parameters, and example prompts.
